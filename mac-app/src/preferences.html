Sync folder

Every change on the dashboard is written here. A newer dashboard.html dropped in this folder loads on its own.

Looking up the folder…
  • campus-copilot-changes.txt — latest summary, replaced on each change
  • campus-copilot-state.json — full dashboard state
  • campus-copilot-history.log — timestamped history
  • dashboard.html — optional update the app watches for
  • campus-copilot-chat-outbox.json — messages the student sends
  • campus-copilot-chat-inbox.json — replies the app watches for
